# ChurchDAW 1.6.25-r2

Registro da publicação emergencial do instalador Windows `r2`, criado para restaurar a compatibilidade com o auto update das versões anteriores.

- O conteúdo instalado do aplicativo é idêntico ao da versão 1.6.25 original.
- Somente a assinatura Authenticode de teste do instalador externo foi removida.
- A integridade continua protegida pela política RS256, HTTPS e SHA-256.
- A política publicada é a serial 31.
- A política de rollback preparada é a serial 32.
- O instalador antigo `ChurchDAW-1.6.25-Setup.exe` foi removido da hospedagem após a validação do `r2`.

Os arquivos JSON desta pasta são artefatos gerados e assinados da publicação.
