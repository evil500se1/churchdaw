## Notes (English, paste into App Store Connect)

Thank you for the opportunity to provide the requested information. We uploaded ChurchDAW 1.6.26 (build 2026.8.16) and attached a physical-device recording.

ChurchDAW is a live-worship instrument workstation for church keyboardists. It plays its own pianos/timbres, continuous pads, native organ, and live scenes. It is not a studio DAW and does not host third-party plug-ins on iOS.

This build has no account, registration, login, account deletion, demo credentials, In-App Purchases, subscriptions, checkout, ads, tracking, or social/user-generated content.

1) SCREEN RECORDING
The attached file “ChurchDAW-AppReview-iPad-26.6.mov” is a 67-second recording captured on a physical iPad (10th generation) running iPadOS 26.6. It begins on the Home Screen, launches ChurchDAW, waits for loading, and shows: main mixer with built-in piano; Pad Studio; sample pad playback; Continuous Pad; five note changes by touch; instrument picker; selection of another built-in piano; and return to the mixer. App-generated audio is included. The “Modo palco” (Stage Mode) control is visible.

No permission prompt appeared. The app does not request location, contacts, camera, microphone, or App Tracking Transparency. Microphone input is disabled (0 input channels). Bluetooth is requested only if the user chooses optional wireless MIDI.

2) DEVICES AND OS TESTED
- iPhone 16e — iOS 26.6
- iPad (10th generation) — iPadOS 26.6
Recording device: iPad (10th generation), iPadOS 26.6.

3) FUNCTIONS, AUDIENCE, AND VALUE
ChurchDAW gives church/worship keyboardists reliable pianos, pads, organ, and scene changes without a laptop plug-in host. On iPad it provides built-in timbres, up to five mixer channels, continuous pads, native organ, live scenes/setlist, master/worship reverb, optional library downloads, and Bluetooth/USB MIDI for compatible keyboards and pedals. It is intended for worship keyboardists and music ministers, not children or a social network.

4) ACCESS AND TEST STEPS — NO CREDENTIALS
- Launch ChurchDAW in landscape and wait for the catalog check.
- Tap “Abrir sem baixar” to enter without a large download.
- Select a timbre on the mixer.
- Open Pad Studio and tap a sample pad.
- Open Continuous Pad and tap note buttons while it plays.
- Open a live scene and Libraries. Unavailable packs show “Em breve”; checkout is disabled.
- Optionally connect a Bluetooth/USB MIDI keyboard.
No login, license key, sample account, purchase, or external keyboard is required.

5) EXTERNAL SERVICES
Core audio runs locally using Apple Core Audio/Core MIDI. Over HTTPS, churchdaw.com provides the timbre manifest, signed compatibility policy, and optional official pack downloads. iOS app binaries update only through the App Store. The app uses no account API, payment processor, analytics, crash reporter, ads, tracking, or AI. Desktop licensing and Mercado Pago are not compiled into the iOS app.

6) REGIONAL DIFFERENCES
The app works consistently in all regions. There are no region-locked features, catalogs, or prices. The default UI language is Brazilian Portuguese.

7) REGULATED INDUSTRY / PROTECTED MATERIAL
ChurchDAW is a musical instrument app, not a regulated service. It distributes ChurchDAW-owned timbres/packs, contains no third-party commercial song catalog, and uses no Nord SDK. We are authorized to distribute the app (© ChurchDAW).
